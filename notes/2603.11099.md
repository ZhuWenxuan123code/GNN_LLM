# Graph Tokenization for Bridging Graphs and Transformers

## 一句话结论

GraphTokenizer 用可逆、由数据统计引导的确定性 graph serialization 加 BPE 构造离散结构 token，较清楚地解决了“图如何无损进入 sequence model”的接口问题，但其确定性与下游指标仍不能替代同构重标记、因果干预和 LLM/GNN 责任分离证据。

## 研究问题与真实贡献

- 作者声称解决的问题：现有 Graph Transformer 需要专用架构，连续 graph embedding 或 text-based graph description 可能造成信息损失、序列过长和结构不稳定；作者希望把一般 labeled graph 转成可被标准 Transformer 直接处理的离散 token sequence。
- 方法的真实新增部分：将 reversible edge-covering serialization 与 BPE 组合，并用训练集中的 labeled-edge local pattern frequency 指导 Eulerian/Chinese Postman traversal 的 tie-breaking，形成 Frequency-Guided Eulerian（Feuler）和 Frequency-Guided CPP（FCPP）。
- 与已有方法相比的关键差异：Graph tokenizer 被定义为 `Phi = T o f`，即 deterministic graph serialization `f` 后接离散 BPE `T`；这不同于只输出 continuous graph embedding、pooling/coarsening 或 vector quantization 的 neural graph tokenization。

## “图结构”的具体含义

- 结构粒度：局部 labeled edge pattern 用于 traversal priority；edge-covering walk 保留全图 topology；BPE 进一步形成 2+ 节点的局部/中尺度结构 token。
- 图信息输入形式：labeled graph `G=(V,E,L,Sigma)`，节点和边属性需能映射到离散 symbol alphabet；Feuler/FCPP 输出交替的 node-edge-node symbol sequence，再经过 BPE merge。
- 信息路径：`Graph -> local pattern statistics -> reversible deterministic serialization -> BPE structural tokens -> BERT/GTE encoder or GPT-style decoder -> graph prediction/generation`。作者还将 GraphGPT/LLAGA 适配为 textualized graph baseline，而不是把 GraphTokenizer 本身当作 GNN-LLM projector。
- GNN 是否可能已经完成主要计算：系统中没有 GNN；图结构的覆盖、可逆性和顺序选择由显式 serialization algorithm 完成，Transformer 主要承担 token sequence 的表示学习与预测。因而它是“结构接口先验 + sequence model”的边界案例，不能据此证明 LLM 内部完成了 topology reasoning。

## 方法机制

给定训练图集 `D`，方法先统计所有 labeled-edge pattern `p=(L(u),L(e),L(v))` 的频率 `F(p)`。Feuler 在 Hierholzer traversal 中按 `F` 和固定 lexical rule 选择下一条未访问边，使每条无向边以相反方向覆盖；FCPP 则把频率写入边权，再在 Chinese Postman Problem 中求 edge-covering walk。序列包含节点、边和节点的交替符号，因此可以用逆 serialization 恢复 topology up to isomorphism。

随后在所有 serialized sequences 上训练 BPE。每次把最频繁的相邻 symbol pair 合并为新 token，保存 merge rules；推理时先使用相同 `F` 序列化，再按 merge-rule 顺序编码，解码时逆序展开 BPE 并调用 `f^-1`。作者默认使用 Feuler+BPE，并用 GT+BERT（BERT-small，约 15M 参数）与 GT+GTE（GTE-base，约 115M 参数）做 graph-level classification/regression；MNIST grid graph 上另做 unmodified decoder-only Transformer 的 autoregressive generation。没有冻结/训练 LLM projector 的 Graph-LLM alignment 过程，也没有 learned graph encoder。

## 实验设计与结果

- 数据集与任务：14 个公开 graph-level classification/regression benchmark，涵盖 Mutagenicity、Proteins、OGBG-MolHIV、ZINC、AQSOL、QM9、COIL-DEL、COLORS-3、Synthetic、DD、Peptides、Twitter、DBLP 等；另在 MNIST grid graph 做生成 proof-of-concept。
- 数据划分：论文使用各 benchmark 的统一预处理与 data splits，并在五次独立运行上报告均值和标准差；没有将 node relabeling、isomorphic pair 或 held-out topology family 作为单独测试 split。
- Baseline：GCN、GIN、GAT、GatedGCN、GraphGPS、Exphormer、GraphMamba、GCN+、Graph Transformers、FragNet、Graph-ViT-MLPMixer、HAN、ChebNet；附录加入 GraphGPT 和 LLAGA 的 textualized adaptation。
- 主要指标与结果：主表中 GT+GTE 的 MOLHIV AUC 为 `87.4 (0.2)`、COIL-DEL ACC 为 `89.6 (0.2)`、Peptide-func AP 为 `73.1 (0.2)`、ZINC MAE 为 `0.131 (0.007)`、QM9 MAE 为 `0.071 (0.005)`；ZINC 上 BPE 将序列压缩至约原始长度的 10%，训练速度示例约提升 `2.5x`。GraphGPT/LLAGA 在 textualized COIL-DEL 上分别为 `5.6/12.5` ACC，GraphTokenizer 为 `89.6`。
- 关键消融：Feuler 在主表代表性任务上通常优于 BFS/DFS/TOPO/Eulerian/CPP/FCPP；例如含 BPE 的 MOLHIV AUC 为 BFS/DFS/TOPO/Eulerian/Feuler/CPP/FCPP=`72.3/76.0/73.2/84.5/87.4/86.9/86.4`，COIL-DEL ACC 为 `81.2/79.1/75.6/84.1/88.0/89.6/89.4`。去掉 BPE 后大多下降；ZINC 上 `K=2000` 达到 `10.84x` compression ratio 和 `0.131` MAE，继续增至 `K=5000` 只得到 `11.34x` 和 `0.132` MAE。
- 是否足以支持作者结论：足以支持“可逆离散接口、BPE 压缩和标准 Transformer 可以在多类 graph-level benchmark 上工作”，也支持显式 graph token 对纯 textualized baseline 的实用优势；不足以支持“LLM 学会了因果拓扑表征”“对任意同构重标记严格 invariant”或“跨拓扑 OOD 已被解决”。

## 局限与潜在捷径

- 连续特征需离散化或另加 continuous channel；作者明确承认 quantization 可能有损，这会破坏“faithful and reversible”假设。当前数据集的 raw node/edge dimensions 并不等于全部能无损进入 symbol alphabet。
- Feuler/FCPP 的 deterministic 依赖 frequency map、固定 lexical tie-break 和 implementation details。论文给出算法和复杂度，但未报告同一 graph 在随机 node relabeling、edge order、起始节点、方向和重复 label 下的 token sequence equality。
- BPE 的局部 token 解释来自词表可视化，不代表 token 是任务相关最小充分结构；token size distribution 也不能替代 key-edge/irrelevant-edge intervention。
- 主要实验是 graph-level readout；作者自己指出在 node/edge-level task 中，BPE 可能把 target entity 合并进 composite token，导致 target addressability 丢失。该限制直接影响 Graph-LLM 中逐节点责任定位。
- GT+GTE 的强结果可能来自显式 edge-covering serialization、BPE 的结构压缩和数据集分布，而不是 Transformer 的可泛化 graph reasoning；没有 GNN-only/readout-only、text shuffle、random-label、hidden-state mediation 或 output intervention。
- GraphGPT/LLAGA 对照将 discrete node labels textualize 以满足 TAG 输入约束，输入接口并不完全 token/parameter/training matched；因此不能把其 COIL-DEL 低分单独解释为 LLM 缺乏 topology 能力。
- 14 个 benchmark 的多域覆盖仍可能是 random/standard split；没有分离 graph-size、density、generator/transitivity、topology-family、semantic OOD，也没有报告预测在 isomorphic graphs 上是否严格相同。

## 与当前研究的关系

- 支持或挑战的研究假设：H1 继续“部分支持”——即使结构接口可逆且系统分数高，也不能直接归因于 LLM causal topology use。H2 得到接口设计层面的正面证据，但缺少实测 permutation protocol。H5 进一步获得“接口 invariance/serialization stability 与 causal use 必须分开”的方法学支持。H3 从“构想”推进为“待验证”：显式、可逆、离散的结构瓶颈可能比单一 continuous projector 更适合做结构审计，但性能优势尚不足以证明因果使用。
- 可以复用的实验或方法：将 `reversible serialization -> BPE -> Transformer` 作为 GraphToken/IP-GLLM/HLM-G/EDT-Former 的离散接口对照；复用 Feuler/FCPP、BPE `K`、sequence compression、token-size distribution、decode fidelity 和 `10 relabelings` 的组合评测。
- 尚未解决的关键问题：在保留重复 node/edge labels 的真实图上，frequency-guided traversal 是否真的对 arbitrary isomorphism 生成相同或等价序列？BPE merge 是否放大某种 serialization order？如果用相同 graph token 输入 LLM，LLM hidden state 与 final output 是否仍对等价重标记稳定？

## 可证伪的新想法

- 假设：H3：一个同时满足 decode fidelity、等价序列化稳定和可干预 target addressability 的离散 structural bottleneck，会比 continuous graph projector 更容易建立可验证的 Graph-LLM topology evidence；但它只有在关键/无关 topology intervention 和责任分离后仍有效，才具有 causal-use 解释力。状态：待验证。
- 最小实验：在同一批带离散 node/edge labels 的 graph 上分别运行 Feuler+BPE、canonical SMILES/edge-list、continuous graph-token baseline；对每个 graph 做 `10 relabelings × 4 edge orders × 3 serialization starts/directions`，记录 serialized sequence equality、BPE token equality、decode isomorphism、token count、Transformer hidden distance、prediction equality 和 output KL。再构造固定 node text/features 的 key-edge/irrelevant-edge matched pairs，计算 direction accuracy 与 irrelevant-intervention stability。
- 对照组：GraphTokenizer+BERT/GTE、同一 Transformer 的 raw edge-list/BFS/DFS/Eulerian、GNN-only、readout-only、text-only、random-label/text shuffle、shuffled graph embedding，以及 GraphToken/IP-GLLM/HLM-G 的 continuous connector；molecular branch 额外加入 AMORE 的 3+ valid SMILES、no-RAG 和 EDT-Former dynamic-token ablation。
- 支持条件：等价变换下 token/hidden/output 稳定；decode fidelity 为 100%；关键边干预方向正确、无关边稳定；离散 bottleneck 的 full model 在 direction accuracy、held-out topology-family PGR 上超过 readout-only/text-only，且不因换 serialization/order 大幅波动。
- 失败或否定条件：任意 relabeling 造成 sequence/token/prediction flip；重复标签下 tie-break 依赖原 node index；BPE token 不能可靠 decode；readout-only/GNN-only 复现 full direction accuracy；或 GraphTokenizer 只在 standard random split 有优势、在 size/density/topology-family holdout 上崩溃。

## 可信度与待核验项

- 直接由全文支持的事实：论文定义 `Phi=T o f`、labeled graph、reversibility/determinism、Feuler/FCPP、BPE encode/decode、14 个 benchmark、GT+BERT/GT+GTE、主要表格、serialization/BPE ablation、token vocabulary visualization、MNIST autoregressive proof-of-concept、GraphGPT/LLAGA textualized comparison，以及 continuous-feature、node/edge-level 和 scalability limitations。
- 我的推断：图结构的显式恢复与序列化发生在 Transformer 之前；因此该系统的高性能更像是“可逆结构输入 + sequence model”的边界案例，而不是已证明 LLM 在内部完成 topology causal computation。GraphGPT/LLAGA 的低纯结构分数也只能作为适配后的边界对照。
- 待核验：论文的“almost invariant to graph permutation”尚缺逐样本 empirical test；需要用官方 code 在重复 labels、起点/方向、edge order、随机 relabeling 和 disconnected components 上核验 deterministic output。还需验证不同 dataset split 是否包含 hidden leakage、BPE codebook 是否只用 train graph、以及 continuous feature serialization 在实现中是否真正无损。
