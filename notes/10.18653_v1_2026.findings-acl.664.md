## 一句话结论

GenNIE 证明在知识图谱节点重要性估计中，把 relation-aware GNN、MoE projector、structure-guided cross-attention、global soft prompt 和 LLM 生成式读出组合起来可以取得很强的任务结果；但现有实验主要证明“联合文本与结构输入对 NIE 有用”，还不能证明冻结 LLM 或 LLM 内部机制对图拓扑进行了可置换、可干预、可泛化的因果利用。

## 研究问题与任务

论文研究 heterogeneous knowledge graph 上的 node importance estimation（NIE）。图由节点、关系类型和实体文本属性组成，目标是预测节点的 popularity 或 centrality 类重要性分数。数据集包括 FB15K、TMDB5K、MUSIC10K 和 DBLP，标签分别来自 page views、movie popularity、artist hotness 和 citation count。作者将原始分数进行 log smoothing 并归一化到 0 到 100，再让模型以离散 score token 进行 teacher forcing 生成。

这不是纯粹的结构重建任务，而是一个带有明显语义与标签先验的下游 ranking/regression 任务。实体名称、描述、关系类型和流行度标签之间可能存在预训练语义关联，因此必须把“使用了图结构”与“使用了节点文本或流行度语义”分开。

## 方法概述

1. 对全图节点计算 Node2Vec 初始 embedding。
2. 使用 L 层 predicate-aware multi-head attention 聚合 L-hop 局部子图，relation embedding 作为 attention bias，并加入 self-loop relation，得到 structural embedding。
3. 使用多个两层 MLP experts 和 gating 组成 MoE projector，将 structural embedding 投影到 LLM hidden dimension。
4. 用 structural embedding 作为 query，对目标实体的文本 token embedding 做 structure-guided cross-attention，得到对齐表示。
5. 将 global learnable soft prompt 置于 instruction 和目标文本之前，用于跨样本捕获全局 scoring pattern。
6. 对 structural embedding 添加 label-aware supervised contrastive learning：真实重要性差异小于 δpos 的节点对作为正例，大于 δneg 的节点对作为负例，并按 score gap 加权。
7. 冻结 LLM backbone，仅使用 LoRA 等参数高效适配方式训练图模块、投影层、soft prompt 和生成相关参数。总损失为 generation loss 加 λ 倍 contrastive loss，论文设置 λ=0.5。

主要实现超参数包括：Python 3.10.19、DGL 2.4.0、CUDA 12.1、单张 NVIDIA L20 48GB；LoRA rank=16、alpha=32、dropout=0.05；temperature=0.1、δpos=2、δneg=10。论文报告 1.1B、3B 和更大 LLM 变体的敏感性结果。

## 主要实验结果

### 主结果

GenNIE 在四个数据集上报告很高的 NDCG@100。GenNIE 1.1B 的结果为：FB15K 0.9755、TMDB5K 0.9098、MUSIC10K 0.9592、DBLP 0.9696；对应 Spearman 分别为 0.9081、0.7765、0.6881、0.5695。GenNIE 3B 在部分数据集上的 Spearman 进一步提高，例如 FB15K 为 0.9204、TMDB5K 为 0.8092、MUSIC10K 为 0.7364、DBLP 为 0.5881。

这些数字说明系统对于当前 NIE benchmark 有效，但不能单独说明模型是否利用了可泛化的拓扑机制，因为标签本身就是 popularity、hotness、citation 等具有强语义和分布先验的指标。

### 消融

在 TinyLlama-1.1B 设置下，FB15K 的 full 模型 NDCG@100/Spearman 为 0.9755/0.9081，MUSIC10K 为 0.9592/0.6881。去掉 contrastive learning 后分别降至 0.9518/0.8313 和 0.9434/0.6551；去掉 soft prompt 后为 0.9634/0.8077 和 0.9145/0.5271；去掉 cross-attention 后为 0.9385/0.7920 和 0.9110/0.5050；去掉 textual attributes 后为 0.8780/0.6826 和 0.7553/0.1012；用 MLP projector 替代 MoE 后为 0.9512/0.8377 和 0.9490/0.5925。

最关键的 "w/o Topological Injection" 去掉了 GNN encoder 和 MoE projector，FB15K 结果降至 0.7162/0.1104，MUSIC10K 降至 0.6700/0.0913。这个对照支持“当前完整系统需要一个拓扑输入路径”，但它同时改变了结构编码器、投影器和参数量，不能定位是 GNN、Node2Vec、MoE、结构条件 cross-attention，还是由这些模块产生的可读出特征在起作用。

### Zero-shot transfer

作者以 FB15K 训练，再测试 MUSIC10K 和 TMDB5K。GenNIE 的结果明显高于若干基线：在 MUSIC10K 上 NDCG@100/Spearman 为 0.9171/0.5907，在 TMDB5K 上为 0.8172/0.5519。这个结果表明系统有一定跨数据集迁移能力，但该设置同时改变了关系类型、标签语义、图分布和文本分布；它属于 cross-domain transfer，不是同一任务下的 topology-family OOD 或等价图置换测试。

### Soft prompt 与 contrastive clustering

作者在 TMDB5K 上按 high/middle/low betweenness 分组，报告 soft prompt 在三组上的收益，低 betweenness 组收益尤其大。这个分析将测试节点按中心性分组，不能视为结构的因果干预。

作者还对 structural embedding 做 K-means，并以 ground-truth importance 分组计算 NMI/ARI。完整模型在 TMDB5K 上 NMI/ARI 为 0.622/0.642，去掉 contrastive learning 后为 0.312/0.328。由于 contrastive loss 本身直接使用 importance score 的差异定义正负对，这个结果是 label-aligned separability，不能替代对未见拓扑属性的结构解码测试。

### LLM 敏感性与关系迁移

论文比较了 Qwen、TinyLlama、Llama 和 Gemma 等模型，规模增大通常提高 Spearman，但不同模型在不同数据集上仍存在差异。附录中 FB15K 到 MUSIC10K 的关系迁移对照显示：zero-shot 为 0.9171/0.5907，Relation-Tuned 为 0.9317/0.6385，Fixed-Random 为 0.9352/0.6721，full supervised 为 0.9635/0.7364。这个结果提示迁移差距不只来自关系词语义，但 Fixed-Random 仍是训练分布内的结构任务对照，不能建立拓扑因果结论。

## 按四层证据审计

| 证据层 | 本文证据 | 结论 |
|---|---|---|
| 结构被输入 | Node2Vec、L-hop relation-aware GNN、relation bias、MoE projector、topological injection | 已满足。结构路径在系统中是显式的 |
| 结构可解码 | structural embedding 的 NMI/ARI 与 ground-truth importance 分组；没有未见拓扑属性 probe | 部分满足。现有 probe 被训练标签对齐，不能视为 topology decoder |
| 置换/同构一致性 | 未见随机节点 relabeling、同构图输出 equality、edge-order、serialization 或 multi-view 一致性测试 | 不满足 |
| 反事实因果利用 | 只有模块消融、text-only/structure-only、关系迁移和 cross-domain transfer；没有 fixed-text key-edge/irrelevant-edge intervention | 部分满足。支持组件重要性，不支持拓扑方向与责任归因 |
| 跨拓扑泛化 | FB15K 到 MUSIC10K/TMDB5K 的 cross-domain transfer | 部分满足。不是 topology family、生成器、密度、同任务图规模或 transitivity OOD |
| shortcut control | 有 text-only、structure-only、MLP projector、Relation-Tuned/Fixed-Random 等对照 | 部分满足。缺少 text shuffle、label shuffle、degree/centrality-only、capacity-matched readout、随机关系和等价重标号 |

## 三类不足与证据等级

### 作者明确承认

论文限制部分明确指出当前研究使用 static KG，节点重要性可能随时间变化，未来需要 temporal NIE benchmark。论文没有把缺少 permutation test、fixed-text intervention 或 LLM responsibility split 作为明确 limitation。代码仓库 README 说明目前提供 core implementation，case-study datasets 和更多 ablation experiments 计划在论文接收后上传。

### 实验直接暴露

- 去掉 textual attributes 和去掉 topological injection 都会显著降分，说明当前任务需要文本和结构两类输入路径的联合信号。
- 去掉 contrastive learning、soft prompt、cross-attention 或 MoE projector 都会改变结果，说明各模块对当前 benchmark 有贡献。
- cross-domain transfer 的收益明显，但新数据集同时改变关系、标签、文本和图分布。
- label-aware contrastive clustering 能把按真实 importance 划分的节点聚成更清晰的簇，但该评价目标与训练标签直接相关。

### 研究者推断

- "w/o Topological Injection" 将 GNN、Node2Vec-derived structural signal、MoE 和相关连接路径整体移除，是系统级路径消融，不是 parameter-matched responsibility split。
- structural embedding 被 supervised contrastive loss 直接按 ground-truth score gap 组织，LLM 可能只需读取一个已经被标签分离的 score manifold；这不能证明 LLM 自身进行拓扑推理。
- popularity、page views、artist hotness 和 citations 可能与实体名称、描述、关系词和预训练语料相关。text-only 的性能下降不能排除文本仍在使用这些 shortcut。
- 没有 fixed-text 下的 key-edge/irrelevant-edge intervention，因此无法区分真正的结构方向信息与邻居内容、节点度、中心性、边顺序或局部统计。
- cross-domain transfer 不能替代 topology-family OOD；迁移性能可能来自任务先验、标签语义或大图/小图分布差异。
- 用重要性标签定义 probe 分组所得到的 NMI/ARI 是目标标签可分性，不是对未见结构性质的可解码性。

## 与当前研究问题的关系

本文与当前主线最相关的部分是：它提供了一个直接把图编码、文本语义和 LLM 生成读出放在同一个系统中的真实案例，并且同时报告了 text-only、structure-only、projector、soft prompt、contrastive learning 和跨数据集迁移。它因此是检验“强任务结果是否等于 LLM 因果利用拓扑”的重要正例。

本文不能替代以下证据：结构序列化是否可逆；节点置换和 edge-order 变化是否保持输出；结构改变时文本 token 是否固定；key edge 与 irrelevant edge 是否有方向性差异；parser、GNN、LLM 和 readout 谁承担了结构责任；在相同任务标签下换 topology generator、density、transitivity 或 graph scale 是否保持效果。

## 最近相关工作与最小差异

| 工作 | 已有贡献 | 与 I1 的最小实质差异 |
|---|---|---|
| GenNIE（本文） | relation-aware GNN、MoE、cross-attention、global soft prompt、label-aware contrastive learning 用于 NIE | I1 不再提出这些模块，而是把 fixed-text intervention、responsibility split、等价图 equality 和 topology-family OOD 作为闭环协议 |
| GraphTokenizer | 用 Feuler/FCPP 等序列化与 BPE 将图转为可处理 token，并强调可逆图表示 | I1 要求在多次 relabeling、edge order、start/direction 下实测 parse/isomorphism/output equality，并测试 causal topology use |
| Graph-KV | 在 LLM 侧使用 graph-aware KV mask、共享 positional embedding 和路由机制 | I1 要求加入 mask-only matched-budget 对照，固定文本后区分结构 mask、邻居语义与 readout 责任 |
| NT-LLM | 用 anchors 和 relative-distance 等方式将图节点信息注入 LLM | I1 额外要求 permutation/equivalence、irrelevant-edge 和 topology-OOD 证据，避免把输入接口收益直接解释成拓扑推理 |

因此本论文强化了 I1 的适用范围，但没有形成第二个独立 Idea：在 node-importance 类任务中，必须先通过 semantic-sufficiency/structure-essential gate，再评估离散 graph tokenizer 的解码、置换、干预、责任和 OOD 属性。

## 对 I1 的强化与可证伪协议

### 强化后的假设

只有当 graph representation 同时满足结构可解码、等价置换保持一致、fixed-text 下 key topology intervention 改变预测而 irrelevant topology 不改变，并且责任可定位到 parser/GNN/LLM/readout 中的明确组件时，Graph-LLM 的增益才可被解释为 causal topology use。对 GenNIE 这类标签驱动的结构编码器，还必须控制 supervised label leakage。

### 最小实验闭环

1. 使用固定文本、固定 token length 和固定参数预算，比较 text-only、GNN/readout-only、LLM-only、readout-only、random-text、text-shuffle、label-shuffle 和 degree/centrality-only。
2. 对同一图做至少 10 次随机节点 relabeling、4 种 edge order、3 种起点/方向；验证 decode 后图同构、结构 token equality/等价性以及最终预测 equality。
3. 在保持节点文本和文本 token 完全不变的条件下，做 key-edge add/remove、irrelevant-edge add/remove、edge direction/role swap，以及 degree-matched topology counterfactual。
4. 将 parser、GNN、projector、LLM、adapter 和 readout 分开冻结/替换，报告每一层的结构 probe 和预测差异；对 contrastive loss 使用 score-shuffle/random-label 版本，避免把标签分离误当作拓扑解码。
5. 在同一 NIE 标签生成规则下，更换 topology generator、density、transitivity、community structure、graph scale 和 partial-access ratio，报告 topology-family OOD；将 random-walk summary 与 exact-neighborhood 输入分开。
6. 对失败样本给出方向性指标：key topology 改变的 effect size 应显著高于 irrelevant topology 改变，且等价 relabeling 的差异应接近零。

### 可证伪结果

若 text-only、degree-only 或 score-shuffled structural embedding 在匹配预算下达到完整模型；或 key-edge 与 irrelevant-edge 的 effect size 无差异；或随机重标号导致输出显著变化；或拓扑族 OOD 下性能崩溃而文本/读出基线保持稳定，则应反驳“LLM 对拓扑进行了因果、可泛化利用”的解释。相反，只有在上述控制同时通过时，I1 才能从“候选”向更强证据升级。

## 对研究地图的影响

- H1：从“结构输入是否真的进入模型”得到更强的正例支持，但仍不是因果证明。
- H10：label-aware structural objective 和 global soft prompt 可以显著改善当前任务，但其收益可能是标签对齐/跨样本先验，不应直接等同于结构推理。
- H11：textual attributes、结构模块和 LLM readout 之间存在明显责任混合，必须做 matched-budget component split。
- H14：进一步支持“结构增益是 task-conditional”；在节点重要性任务中，semantic sufficiency 与 structure essentiality gate 是前置条件。
- H15：cross-domain transfer 仍不能替代 topology-family OOD；partial access、图规模和拓扑族应作为独立轴。
