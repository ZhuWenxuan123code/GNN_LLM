# When Graph Tokens Sink: A Mechanistic Analysis of Graph Language Models

## 基本信息

- Paper ID：arXiv:2606.03712
- 作者：Ding Zhang、Runtao Zhou、Wenqing Zheng、Rizal Fathony、Bayan Bruss、Chirag Agarwal
- 年份与发表状态：2026；arXiv v1，2026-06-02
- 论文页面：https://arxiv.org/abs/2606.03712
- PDF：[`2026_Zhang_When_Graph_Tokens_Sink_Mechanistic_Analysis.pdf`](../papers/2026_Zhang_When_Graph_Tokens_Sink_Mechanistic_Analysis.pdf)
- 阅读级别：全文精读
- 对应证据线：结构被使用（中间表示/任务级间接）、结构反事实（token-level intervention）、shortcut control（部分）；不覆盖 graph-level 因果拓扑闭环

## 一句话结论

Graph-token 的 activation saliency、attention 位置和 token pruning utility 可以彼此脱钩，因此“模型内部出现显著 graph token”不能直接证明 LLM 因果地使用了图拓扑。

## 研究问题与真实贡献

- 作者声称解决的问题：解释 graph language models 中的 graph sink tokens，即在少数 hidden dimensions 上产生异常大 activation、且倾向出现在 graph-token 序列开头的 token，是否承载主要图信息、是否获得更高 attention，以及移除或移动它们是否会损害下游任务。
- 方法的真实新增部分：提出基于 sink dimensions 的 graph sink 检测，使用 activation magnitude 定位样本级 sink positions，并在 LLaGA、TEA-GLM 上联合执行 attention 分布分析、top-2 sink pruning、随机 non-sink pruning、sink/non-sink swap、sink repositioning 和 logit lens。
- 与已有方法相比的关键差异：研究对象从“图 token 是否有任务增益”转向 token-level mechanistic attribution；但干预对象仍是 token 位置/激活，不是保持节点文本和标签语义不变的 graph topology counterfactual。

## “图结构”的具体含义

- 结构粒度：以中心节点及其多跳邻居为主的局部邻域；没有直接构造 graph-level topology family intervention。
- 图信息输入形式：LLaGA 使用中心节点与按 hop 采样的邻居结构，经 node-aligned graph tokens 和固定模板输入 LLM；TEA-GLM 使用 GraphSAGE 聚合中心节点表示，经 projector 生成 `K=5` 个 learned graph tokens。
- 信息路径：`Graph → GraphSAGE/SimTeG GNN → Projector/graph tokens → frozen Vicuna LLM → node classification/link prediction output`。
- GNN 是否可能已经完成主要计算：是，至少不能排除。TEA-GLM 的中心节点表示由 GraphSAGE 先聚合，LLaGA 的图 token 也在 LLM 前由图编码/采样模板构成；本文没有 GNN-only、LLM-only、readout-only 或 solver-disabled responsibility split。

## 方法机制

论文先在 LLM hidden states 上识别 sink dimensions，再定义每个 graph-token position 的 sink activation magnitude。主实验阈值为 `τ=15`，LLaGA 平均 500 个样本，TEA-GLM 平均 300 个样本。LLaGA 使用公开的 `vicuna-7b-v1.5-16k`，节点表示由 SimTeG 产生，ND 模板最多两跳、每跳 fanout 为 10，并将序列 padding 到固定长度；TEA-GLM 冻结 Vicuna，使用两层 GraphSAGE（hidden 2048、output 4096）和 `K=5` 个 graph tokens，训练 graph encoder/projector/graph-token embeddings，checkpoint 在 ogbn-Arxiv 上训练后零样本迁移到 Cora 与 PubMed。作者比较 graph sink 与 non-sink 的 attention，并在保持其余输入不变时删除、交换或重排 token；logit lens 用于查看中间层的 top-1 vocabulary decode。

## 实验设计与结果

- 数据集与任务：Cora、ogbn-Arxiv、PubMed；node classification 与 link prediction。
- 数据划分：沿用 LLaGA/TEA-GLM 的任务设置；TEA-GLM 在 ogbn-Arxiv 训练并向 Cora/PubMed 零样本迁移。不是专门设计的 topology-OOD split。
- Baseline：原始模型；删除 top-2 graph sink；随机删除两个 non-sink（15 个随机种子）；sink 与 non-sink swap（5 个随机种子）；LLaGA 另测将 sink 移到 graph-token sequence 前端。
- 主要指标与结果：在 node classification 中，LLaGA 的 top-2 sink pruning 为 `77.0/88.0/95.0`（Arxiv/Cora/PubMed），而 non-sink pruning 降至 `74.36±1.44/80.48±2.47/89.16±4.58`；TEA-GLM 的 top-2 sink pruning 基本保持 `56.67/13.0/83.67`，non-sink 为 `44.40±1.13/12.80±1.72/83.40±1.09`。Link prediction 结果更混合：LLaGA top-2 sink 为 `90.80/83.60/87.60`，non-sink 为 `90.76±0.39/82.04±0.39/87.08±0.37`；TEA-GLM top-2 sink 为 `52.67/60.33/60.67`，non-sink 为 `54.04±3.22/59.20±2.35/61.42±2.62`。
- 关键消融：sink activation dimension、position distribution、attention、sparsity、pruning 后新 sink、repositioning、swap 和 logit lens。LLaGA 的 top-2 sink 多为 `[PAD]`，center token 从未成为 sink；TEA-GLM 的 sink 常在位置 0/1，但 attention 往往集中在后续 graph-token positions。logit lens 显示 sink token 多为泛化的 citation-domain 词，而非任务标签或可读拓扑。
- 是否足以支持作者结论：足以支持“graph sink activation 不等于 attention/functional importance”的 token-level 结论；不足以支持或否定“LLM 是否因果使用 graph topology”的 graph-level 结论。

## 局限与潜在捷径

作者明确说明只研究两个代表性 graph language model，并把 graph-token construction、placement 和 alignment 的改进留作未来工作。实验没有 node relabeling/isomorphism、同文本关键/无关 topology counterfactual、text shuffle、random-label、GNN/LLM/readout responsibility split 或 held-out topology-family。`[PAD]` 的早期 sink、固定长度模板、graph-token 的位置和序列稀疏性可能产生 activation/attention 伪影；TEA-GLM 的 citation-domain zero-shot transfer 还可能让 logit lens 的 `paper` 等词反映预训练域而不是拓扑。pruning/swap 只报告相对 token 重要性，不能定位具体边、节点或路径的拓扑责任；改变 token 顺序本身也可能同时改变 positional pattern。

## 与当前研究的关系

- 支持或挑战的研究假设：支持 H1 的边界判断，强化 H5 的“robustness/saliency 与 causal topology use 可分离”，并新增一个待验证机制假设：H13“graph-token activation saliency/attention dominance 可能与 task-specific topology utility 脱钩”。它直接强化 I1 中必须同时报告 saliency、attention、token intervention 和 graph-level topology intervention 的要求。
- 可以复用的实验或方法：sink-dimension 统计、position histogram、top-2 sink vs random non-sink pruning、swap/reposition、attention share 和 logit-lens probe，可作为 I1 的 pre-intervention diagnostic；但必须在 matched graph pairs 上补充 graph-level intervention。
- 尚未解决的关键问题：在固定节点文本、特征、prompt 和输出格式下，关键拓扑改变是否能稳定改变答案，而 irrelevant topology 改变是否保持答案；这种方向性是否由 LLM、GNN 或 readout 单独复现；等价重编号/edge order 下 sink map 和最终输出是否稳定。

## 可证伪的新想法

- 假设：graph-token 的 sink score、attention share 和 token pruning delta 不是 topology causal responsibility 的充分统计量；只有把它们与 fixed-text key/irrelevant topology intervention、等价变换 equality 和 component responsibility split 联合起来，才能识别 LLM 是否真正利用拓扑。
- Idea 推导链：当前方法 → activation outlier 常位于 `[PAD]`/早期位置且不必然具有 attention 或任务功能重要性 → sink/saliency 可能是架构与序列稀疏性现象 → 对 I1 增加 sink-aware diagnostic，再用地址化 graph-token/edge intervention 检验 topology responsibility → 若 sink 指标与方向正确的关键拓扑干预无关，则放弃“显著 token 即结构瓶颈”的解释。
- 结合的历史论文：GraphTokenizer（arXiv:2603.11099）、GRAIN（arXiv:2608.27142）、CausalGraph2LLM（doi:10.18653/v1/2025.findings-naacl.110）。
- 最接近工作：GraphTokenizer 提供 reversible/deterministic discrete serialization；GRAIN 提供 exact graph IR recovery 与 external solver 边界；CausalGraph2LLM 提供 encoding/order 与 downstream `do(X=x)` 诊断。这里仅采用它们公开论文中的协议与证据边界，不把各自的任务分数当作 causal topology proof。
- 与相邻工作的最小实质差异：I1 不把 activation sink、attention、token pruning 或单一 structural token 作为方法终点，而要求同一 matched sample 上同时满足 decode-isomorphism、`10 relabelings × 4 edge orders × 3 starts/directions`、fixed-text key/irrelevant topology direction、text shuffle、GNN/LLM/readout split 和 held-out topology-family。
- Novelty 状态：已初步区分；“sink-aware graph-token diagnostic”本身不是独立方法创新，I1 仍只能以联合评测/可定位干预协议作为候选贡献；SOG 的 one-structural-token 设计进一步降低了单一离散 token 的方法新颖性。
- 最小实验：在同一 GraphTokenizer/I1 tokenizer 与 matched graph pairs 上，记录每个 graph-token 的 sink score、attention share、top-2 sink/non-sink pruning delta；同时做 `10 relabelings × 4 edge orders × 3 starts/directions`、graph decode isomorphism、固定文本 key-edge/irrelevant-edge intervention，并分别运行 GNN-only、LLM-only、readout-only、text-shuffle 和 solver-disabled 条件。
- 对照组：top-2 sink、随机 non-sink、attention-top、random token、opaque lexical anchor、raw serialization、continuous projector、Graph-KV mask-only，以及固定图结构但打乱文本/标签的对照。
- 支持条件：等价变换下 sink map/输出稳定；关键 topology 干预的 direction accuracy 显著高于 irrelevant/random；LLM-side intervention 在控制 GNN/readout 后仍保留增量效应，并在 held-out topology family 上保持。
- 失败或否定条件：sink 主要是 `[PAD]`/位置/长度产物；sink 与关键 topology direction 无关；random non-sink 或 readout/GNN-only 复现全部效应；或仅 parser recovery/standard split 提升而 topology-OOD 失败。
- 资源和实现风险：需要统一 token address、graph pair 生成、外部 solver 与组件缓存；当前本地环境缺少 `torch`、`dgl`、`networkx`、`rdkit`、`transformers`，暂不能直接复现 LLaGA/TEA-GLM 或 GraphTokenizer runtime，只能先完成协议与静态审计。

## 可信度与待核验项

- 直接由全文支持的事实：activation sink 多出现在早期 graph-token positions；LLaGA top-2 sink 常为 `[PAD]`；sink 未表现出稳定更高 attention；top-2 sink pruning 通常不如随机 non-sink pruning 造成性能下降；logit lens 多为 generic/citation-domain vocabulary；论文只覆盖两个代表性架构，并未提供 graph-level permutation/counterfactual/responsibility/OOD 闭环。
- 我的推断：sink 现象可能混合了 padding、位置编码、序列稀疏性和预训练域捷径；token-level functional importance 不能推出 edge/node/topology-level causal responsibility；TEA-GLM 的 zero-shot domain transfer 不能替代 topology-family OOD。
- 待核验：在隔离依赖环境中复现官方模型；确认 sink score 对 node relabeling、edge order、start/direction 的稳定性；完成 fixed-text key/irrelevant topology intervention 和 GNN/LLM/readout responsibility split；检验 sink diagnostic 是否能预测真正的 topology intervention direction。
