# Lost in Serialization: Invariance and Generalization of LLM Graph Reasoners

## 基本信息

- Paper ID：arXiv:2511.10234

- 年份与发表状态：2026；arXiv v3（2026-06-09），标注为 ICML 2026 Workshop on Graph Foundation Models
- 论文页面：https://arxiv.org/abs/2511.10234

## 一句话结论

论文用同一图的 node relabeling、edge/structure reordering、syntax 变体和 spectral tasks 证明：固定序列化上的高准确率不能等价于 permutation consistency 或跨拓扑结构泛化，post-training 降低 relabeling 敏感性也主要可能来自任务性能提升而非真正的不变性。

## 研究问题与真实贡献

- 作者声称解决的问题：系统评估 LLM graph reasoners 对图表示中等价变换的鲁棒性，并检查 post-training 是否带来真正的结构泛化。
- 方法的真实新增部分：把 graph serialization 分解为 node labeling、computational structure（data structure 与内部 edge ordering）和 syntax；在 Erdős benchmark 的 49 个拓扑任务上评估 Qwen、G1 与 gpt-oss，并新增 12 个 spectral tasks 检查未见任务泛化。
- 与已有方法相比的关键差异：不是提出新的 GNN-LLM 接口，而是把“同一图的不同编码”作为独立实验因素，比较 base LLM、专门 fine-tuned graph reasoner 和更大模型；全套分析超过 1.5M 次 model inference。

## “图结构”的具体含义

- 结构粒度：局部邻域、路径、连通性、中心性、匹配、计数等组合/拓扑性质，以及全局 spectral quantities。
- 图信息输入形式：将静态图 (G=(V,E))（可选边权）序列化成 edge-list、adjacency-list 或 adjacency-matrix，再用 plain text、JSON、NetworkX、PyG 等 surface syntax 传给 LLM。
- 信息路径：Graph → serialization / token sequence → autoregressive LLM → textual or numerical answer；没有 GNN、graph encoder、projector 或 graph token 模块。
- GNN 是否可能已经完成主要计算：不适用，因为实验对象是直接读取序列化图的 LLM graph reasoner；但 serialization 的邻居 locality、节点位置和格式可能给 LLM 提供 shortcut，使其不必执行完整的结构算法。

## 方法机制

论文将每个输入写成 task description 与 (\mathcal{S}(G,\ell)) 的 token 序列。node labeling 通过对同一测试图采样 (N=10) 个随机重编号实现，随后 lexicographically sort edges 以尽量隔离 edge-list shuffle；computational structure 比较 edge-list、adjacency-list、adjacency-matrix 及排序/随机化/无向边复制；syntax 比较标准 Erdős encoding、JSON、NetworkX 和 PyG。模型包括未专门训练的 Qwen-3B/7B、在 Erdős 上经 SFT+GRPO 的 G1-3B/7B，以及未专门 graph post-training 的 gpt-oss-20B/120B；敏感性实验对 Qwen 与 G1 采用 temperature 0。spectral benchmark 在 Erdős 测试图的 100 个图上构造 12 个任务，并用 sMAPE、RelMAE 与 reasoning-style（analytical / heuristic / incomplete）分析结果。

| 结构可由中间表示解码 | 否 | 没有对 hidden states 做 structural probe 或 representation intervention。 | 不能判断中间表征是否编码了可恢复的结构。 |

| 结构反事实干预 | 否 | node relabeling、edge ordering 和 syntax 主要保持图关系不变；没有保持文本/节点语义而改变关键拓扑的 counterfactual pair。 | 不能回答模型对任务相关结构干预是否方向正确。 |

## 实验设计与结果

- 数据集与任务：Erdős test set 的 49 个拓扑任务，每个任务 100 个图，共 4,900 个样本；另在其中 100 个图上构造 12 个 spectral tasks。原 suite 中的 `isomorphic_mapping` 因输入结构不同被排除。
- 数据划分：论文使用 Erdős 的测试图评估，并比较在 Erdős 上 post-trained 的 G1 与未专门 graph fine-tuning 的 Qwen/gpt-oss；没有提供独立的 held-out topology family、graph-size extrapolation 或真实世界图任务划分。
- Baseline：Qwen-3B/7B、G1-3B/7B、gpt-oss-20B/120B；没有 GNN-only、text-only 或 graph-only 对照。
- 主要指标与结果：
  1. Node relabeling 后，G1 的 accuracy sensitivity 通常比 Qwen 更明显；论文以 `bipartite_maximum_matching` 为例，原始编号中的连续二分结构在 relabeling 后消失，性能随之下降。Qwen 在数值任务的 output span 往往更大，表明“准确率变化”和“输出不变性”并非同一指标。
  2. Computational structure 的变化会改变计算路径：sorted edge-list 接近 Erdős baseline，adjacency-list 对部分任务产生偏移，adjacency-matrix 常有较大损失；随机打乱 edge-list 会破坏邻居 locality，G1 平均最脆弱。无向边复制可改善对称 locality，但会增加序列长度并伤害部分 counting tasks。
  3. Syntax 不是无害表面变换：G1-3B/7B 的跨格式平均标准差为 9.69%/10.51%，Qwen-3B/7B 为 5.98%/5.86%，gpt-oss-20B/120B 为 5.41%/3.45%；gpt-oss-120B 除 PyG 外各格式约为 88% 平均准确率，显示规模提高了鲁棒性但代价更高。
  4. Spectral generalization 仍弱：G1-7B 在 12 个任务中仅 7 个胜过 Qwen-7B；其 easy/medium/hard 平均 sMAPE 为 20.80/49.58/39.95，Qwen-7B 为 19.73/50.05/51.31。G1-7B 在整体上仅约一半任务的 RelMAE 优于 mean baseline，且复杂任务的人工检查显示会从 analytical derivation 退回 heuristic。
- 关键消融：10 次 node relabeling、edge-list/adjacency-list/adjacency-matrix、sorted 与 shuffled edge ordering、无向边复制、四种 syntax、temperature 0 与原始 0.06 的对照，以及 12 个 spectral task 的 difficulty 分组和 reasoning-style 检查。
- 是否足以支持作者结论：足以支持“序列化敏感性普遍存在、post-training 可能强化数据集/格式捷径、固定格式准确率不足”的结论；不足以支持“模型获得了 permutation-invariant、因果有效或跨拓扑泛化的结构表征”，因为没有 representation probe、结构反事实、text shortcut controls 和 topology-family OOD。

## 局限与潜在捷径

重点风险包括：Erdős 图与任务分布相对集中；G1 在 Erdős 上训练，部分 node labeling 结果可能被训练模板的 positional regularity 解释；edge-list 中邻居连续性可让模型使用 linear-scan shortcut；JSON/NetworkX/PyG 会触发不同的预训练代码先验；没有 real-world node/graph-property prediction、GNN-only 或 same-text/different-topology 对照。论文作者也明确承认模型与 tuning strategy 覆盖仍有限，且尚未扩展到真实世界节点和图属性任务。

## 与当前研究的关系

- 支持或挑战的研究假设：支持 H1 关于“下游准确率不等于结构因果使用”；为 H2 提供直接的 node relabeling 与 edge-ordering 证据；强化 H4 的必要性，因为 invariance、structure-use 和 generalization 必须拆开测量。
- 可以复用的实验或方法：使用同一图的 10 次 node relabeling、normalized output span、edge-list/adjacency-list/matrix 三分解、syntax 四分解，并把 `performance shift` 与 `output variability` 同时报告。
- 尚未解决的关键问题：纯序列化 LLM 的结果能否迁移到 GNN-LLM / GTokenLLM；通过 permutation test 的模型是否也能在 same-text topology counterfactual 和 held-out topology 上做出方向正确的变化；怎样区分“更高准确率带来的表面稳定”与真正的 permutation consistency。

## 可证伪的新想法

- 假设：Graph-LLM 的 permutation robustness 与 causal topology use 是两个可分离维度；模型可以在 10 次 node relabeling 上稳定，却在保持文本语义的 topology counterfactual 上不响应或响应方向错误。
- 最小实验：对同一模型、同一批图和同一目标节点交叉执行 `10 relabelings × edge-order/syntax variants × same-text topology counterfactual`，同时记录原始输出、normalized output span、关键拓扑干预的方向正确率和 held-out topology-family accuracy。
- 对照组：canonical serialization、text-only、graph-only、GNN-only，以及随机无关边干预；控制节点文本、标签分布、图规模和目标答案频率。
- 支持条件：等价重编号/格式变换下输出保持稳定，关键结构干预引起方向正确的输出变化，无关干预保持稳定，并在未见拓扑族上保持该行为。
- 失败或否定条件：若 permutation 稳定性与反事实方向正确率、无关干预稳定性和 topology-OOD 之间无关，或 canonicalization 单独即可获得同等结果，则该假设被否定或需要拆分。

## 可信度与待核验项

- 直接由全文支持的事实：论文的分解框架、模型与数据规模、10 次 node relabeling、edge/syntax ablations、12 个 spectral tasks、主要数值结果、结论与作者列出的 textual-serialization limitations，均由 arXiv v3 HTML/PDF 核验；本地 PDF 为 `%PDF-1.7`、5,008,193 bytes、32 页，首页文本可提取。
- 我的推断：G1 对特定顺序和格式的敏感性很可能包含 positional/locality shortcut；node relabeling 下的稳定性不能单独等价于结构表征不变性；这些结果对 GNN-LLM 的迁移性需要额外实验。
- 待核验：GNN-LLM / GTokenLLM 在相同 10-way relabeling、同构一致性和 same-text topology counterfactual 下是否表现出相同或不同的 failure mode；论文代码与完整数据生成脚本尚未在本轮复现。
