# Revisiting Graph-Tokenizing Large Language Models: A Systematic Evaluation of Graph Token Understanding

## 基本信息

- Paper ID：arXiv:2605.03514
- 作者：Zhongjian Zhang, Yue Yu, Mengmei Zhang, Junping Du, Xiao Wang, Chuan Shi
- 年份与发表状态：2026；arXiv v1 预印本，2026-05-05 提交，未在论文页面确认正式接收
- 论文页面：[arXiv abstract page](https://arxiv.org/abs/2605.03514)
- PDF：[arXiv PDF](https://arxiv.org/pdf/2605.03514)；本地副本：`papers/2026_Zhang_Revisiting_Graph_Tokenizing_LLMs.pdf`
- 阅读级别：全文精读
- 对应证据线：1 图结构编码与 GNN-LLM 对齐机制；3 图结构表征探针与中间层可解释性；4 反事实干预与结构信息的因果利用；6 排除文本、序列顺序和预训练知识捷径的评测方法

## 一句话结论

GTEval 说明现有 GTokenLLM 可以保留并被注意到图 token 中的部分文本/结构信息，但在任务改写、语义改变和结构攻击下表现出明显的模板依赖与文本捷径，因此“图 token 被输入、可解码或被 attention 关注”仍不足以证明 LLM 真正理解并因果使用图结构。

## 研究问题与真实贡献

- 作者声称解决的问题：统一描述 Graph-Tokenizing LLM（GTokenLLM）从 graph input 到 graph embedding、graph token、text output 的变换，并回答模型是否真正理解被压缩到自然语言 embedding space 的 graph token。
- 方法的真实新增部分：提出 GTEval，用 format-level 的 Rephrasing 和 content-level 的 Relabeling、Reversing、Randomizing 四类 instruction transformation 审计 graph-token understanding；同时进行 GI→GE 的结构攻击、GE→GT 的 structural/textual probing 以及 GT→TO 的跨层 attention 分析。[论文原文](https://arxiv.org/html/2605.03514#S2)
- 与已有方法相比的关键差异：它不是再提出一种 Graph-LLM 接口，而是用统一评测管线复测 6 个代表性 GTokenLLM（LLaGA、InstructGLM、GraphGPT、GraphTranslator、TEA-GLM、GOFA），把“固定模板上的任务准确率”与“对等语义或新语义指令的响应能力”分开。[论文原文](https://arxiv.org/html/2605.03514#S3)

## “图结构”的具体含义

- 结构粒度：以 text-attributed graph 的节点邻域为主，包含局部邻域、节点级结构 embedding、GNN message passing 得到的结构信息；实验对象主要是节点分类，另用 link prediction 检查 token 中的边级信息。
- 图信息输入形式：TAG 定义为 `G=(V,E,T)`；节点文本经 text encoder 得到 `X`，邻接矩阵 `A` 通过显式结构 embedding 或 GNN 融入 `Z`，再经 projector 得到 graph tokens `T`，作为 LLM prefix 与自然语言 instruction 拼接。[统一框架](https://arxiv.org/html/2605.03514#S2.SS1)
- 信息路径：`Graph → text encoder / GNN / explicit structure embedding → GE → learned projector → GT prefix tokens → frozen or task-tuned LLM → textual output`。
- GNN 是否可能已经完成主要计算：是，存在明显可能。论文的统一框架允许 GNN/graph encoder 先把任务相关信息压缩进 GE；LLaGA 的 LLM 冻结，GraphGPT、TEA-GLM 等也依赖预训练或对齐后的 graph representation。GTEval 证明的是下游 LLM 对这些 token 的 instruction 响应存在缺口，不能单独证明 LLM 参与了主要结构推理。

## 方法机制

论文把 GTokenLLM 拆成三阶段：GI→GE 将文本和拓扑压缩成 graph embeddings；GE→GT 用 learned projector 对齐到 LLM token space；GT→TO 将 graph tokens 放入 prompt，生成文本输出。作者复测各模型 released checkpoints，使用原始代码与默认超参数，不额外 fine-tune；每个数据集和模型为每种 instruction modification 生成 10 个模板变体，并报告均值和标准差。[统一框架与实验设置](https://arxiv.org/html/2605.03514#S2.SS1)[实验设置](https://arxiv.org/html/2605.03514#S3.SS2)

GTEval 的四种变换为：Rephrasing 保持任务语义只改写表达；Relabeling 替换人类可读的 label space；Reversing 将“最相关”改为“最不相关”；Randomizing 用无关句子替换任务 instruction。这样既测同一结构/同一任务的格式一致性，也测同一 graph token 在任务语义改变后的适应性。[GTEval 定义](https://arxiv.org/html/2605.03514#S3.SS1)

## 结构证据审计

| 证据问题 | 是否提供 | 论文证据 | 我的判断 |
|---|---|---|---|
| 结构被输入 | 是 | 统一框架明确将 `A`、节点文本和 GNN/显式结构 embedding 纳入 GE，再映射到 GT；6 个模型均按该框架复测。 | 证明结构进入 pipeline，但不证明 LLM 端真正使用了结构。 |
| 结构可由中间表示解码 | 部分 | 在 LLaGA 上，使用 GE 或 GT 训练的 GCN 做 link prediction 均明显优于随机初始化特征，且 GT 与 GE 性能相近。 | 这是 structural decodability/probe 证据，不是结构被最终预测因果使用的证据；且主要展示 LLaGA。 |
| 节点置换或同构一致性 | 否 | 论文测试 instruction rephrasing，不是 node renumbering、edge-order change 或 isomorphic graph consistency。 | Q2 仍未推进到直接证据；GTEval 不能替代 permutation test。 |
| 结构反事实干预 | 部分 | 使用 PRBCD 扰动拓扑：GCN 总体准确率从 63.30 降至 16.70，LLaGA 从 89.79 降至 54.40；GraphGPT 与 TEA-GLM 基本不变。[Table 3](https://arxiv.org/html/2605.03514#S4.SS2) | 这是 adversarial structural attack，不是严格的因果干预；没有“只改任务无关结构”的保持标签对照。 |
| 结构被最终预测因果利用 | 未充分提供 | graph tokens 在所有 LLM 层获得非零 attention；但作者同时观察到模型依赖文本、模板和 label mapping，且 attention 只是相关性证据。[GT→TO 分析](https://arxiv.org/html/2605.03514#S4.SS2) | 不能从 attention 或原任务准确率推出 causal utilization；论文反而强化了该缺口。 |
| 跨规模、密度或拓扑泛化 | 否 | 数据集横跨 citation、e-commerce、web link 等领域，但没有受控的 held-out graph size、density、topology family 或 topology-composition split。 | “跨数据集”不等于“跨拓扑泛化”；Q1/Q5 仍开放。 |
| 排除文本或预训练捷径 | 部分 | PRBCD 后 GraphGPT/TEA-GLM 准确率几乎不变；论文指出它们可能主要依赖中心节点文本。LLaGA 的 graph-token 结构攻击下降，但其 content-level 变化仍很差。[作者观察](https://arxiv.org/html/2605.03514#S4.SS2) | 有 shortcut 诊断，但没有 text shuffle、text-only/graph-only、同文本不同关键拓扑的完整控制组。 |

## 实验设计与结果

- 数据集与任务：Cora、Cora-70、Pubmed、OGBN-Arxiv、OGBN-Products、Book-History、WikiCS；主要是节点分类，另以 GCN link prediction probe 评估 GE/GT 的边级结构信息。数据覆盖 citation、e-commerce、web link 三类图域。[Appendix D.1](https://arxiv.org/html/2605.03514#A4.SS1)
- 数据划分：沿用各模型对应 test set 和原始 train/val/test mask；例如 LLaGA 的 Cora/Pubmed 为 60/20/20，OGBN-Arxiv 为 53.7/17.6/28.7，Products 为 8.0/1.6/90.4；GOFA 的 Cora 为 5.2/18.5/76.4。[Table 8](https://arxiv.org/html/2605.03514#A4.SS1)
- Baseline：6 个 released GTokenLLM checkpoints；GCN 作为结构依赖 baseline；GTextLLM（GPT-3.5、Cora 上 GPT-4o，以及 zero-shot/1-hop text prompt）作为文本化图对照。
- 主要指标与结果：6 个模型的原始准确率约为 47%–84%，但 Rephrasing 的整体下降可达约 50%；多数 content-level 指标低于 50%，部分低于 10%。例如 LLaGA overall 从原始 84.29 降到 Rephrasing 81.54，Relabeling 13.52、Reversing 2.70、Randomizing 3.03；InstructGLM 的 Rephrasing 为 56.42，原始为 82.44；GraphGPT 的整体原始/改写为 53.96/44.14。[Table 2](https://arxiv.org/html/2605.03514#S4.SS1)
- 关键消融：对 LLaGA 和 GraphGPT 增加 Rephrasing/Relabeling instruction tuning。见过的变体明显改善，但未见的 Reversing/Randomizing 不稳定甚至下降，例如 LLaGA overall Reversing 由 2.70 变为 1.56、Randomizing 由 3.03 变为 0。[Table 4](https://arxiv.org/html/2605.03514#S4.SS2)
- 是否足以支持作者结论：足以支持“现有 GTokenLLM 对 instruction 变化的理解不完整、存在文本/模板依赖、需要更强评测”的经验结论；不足以支持“LLM 已形成置换一致、因果有效、跨拓扑的图结构表征”。

## 局限与潜在捷径

1. GTEval 的任务变换主要改变自然语言 instruction，不直接改变 graph topology；因此它能暴露 token-to-instruction interface 的脆弱性，但不能替代 permutation/isomorphism 或 topology-OOD 评测。
2. PRBCD 是结构攻击而非保持任务语义的反事实实验。若拓扑攻击同时破坏标签同质性或局部统计，准确率变化的因果含义会变得不唯一。
3. 论文用 text-attributed graphs；中心节点文本、标签名称和预训练语言知识都可能是强捷径。GraphGPT/TEA-GLM 对 PRBCD 的不敏感是文本捷径的提示，不是严格的 text-only 因果证明。
4. 结构 probe、t-SNE 和 attention 只能分别说明信息可解码、表示聚类或被关注；它们都不能单独说明该信息被最终预测因果利用。
5. 自由文本输出通过 `contains` 标签字符串计分；Reverse 只在原始任务答对的样本上统计，Randomizing 的“正确”是“不输出任务标签”。这些设计适合检测模板依赖，但不能完整等价于结构推理能力。
6. 作者说明完整代码、checkpoint 和数据因文件大小/审稿阶段安排未全部公开；论文使用原始代码和默认设置，复现实验仍需核对具体版本。[Appendix D.2–D.3](https://arxiv.org/html/2605.03514#A4.SS2)

## 与当前研究的关系

- 支持或挑战的研究假设：部分支持 H1。论文在 6 个 GTokenLLM 上显示原任务准确率、GT 中保留可探测结构信息、跨层 attention 与真正理解/因果使用之间存在明显断裂；同时，GT 确实保留任务相关文本和结构信息，因此不能把“没有理解”简化成“没有结构信息”。
- 可以复用的实验或方法：把 GTEval 的四种 instruction transformation 作为 interface audit；把 GE→GT 的 link-prediction probe 作为 decodability 层；把 PRBCD 结果改造成保持语义的 topology counterfactual；把“原任务正确→反事实任务正确”的配对样本分析纳入统一证据表。
- 尚未解决的关键问题：GTEval 没有 node permutation/isomorphic pair、同文本不同拓扑的反事实、text shuffle、held-out topology family 或 graph-size extrapolation；无法回答 H2、Q3、Q4、Q5 的核心强版本。

## 可证伪的新想法

- 假设：只有同时通过“instruction invariance + graph counterfactual sensitivity + shortcut controls”的模型，才能被称为对 graph tokens 具有因果有效的理解；单独高原任务准确率、结构 probe 或 attention 不足以通过。
- 最小实验：在同一模型和同一批节点上构造 2×2 评测：Rephrasing/Relabeling/Reversing/Randomizing ×（节点置换、保持文本不变的关键边交换、text shuffle、无关边注入）。要求同语义的置换保持输出，关键结构干预引起方向正确的输出变化，无关边和 text shuffle 不引起不应有的变化；同时记录原任务、text-only、graph-only 和 GNN-only 对照。
- 对照组：原始固定 prompt；只使用中心节点文本的 text-only；只使用 graph token 的 graph-only；冻结 GNN 输出并替换拓扑；随机 token 或随机无关边；一个只训练 label mapping 的 shortcut baseline。
- 支持条件：在不同数据集和未见 instruction/topology split 上，模型同时达到高 permutation consistency、对关键结构干预有稳定且可预测的响应、对无关干预保持稳定，并显著优于 text-only/shortcut baseline。
- 失败或否定条件：只要模型在 text shuffle 后保持同等性能、对关键拓扑改变不敏感、或只在见过的 instruction 上通过而在未见 topology 上失败，就否定“LLM 因果使用 graph structure”的强版本。

## 可信度与待核验项

- 直接由全文支持的事实：GTokenLLM 的三阶段统一形式；GTEval 的四种 instruction transformation；6 个模型的主表结果；PRBCD 结构攻击结果；LLaGA 的 GE/GT link-prediction probe；跨层 attention、instruction tuning 和 GTextLLM 对照；数据集统计与实现说明。
- 我的推断：GraphGPT/TEA-GLM 对拓扑攻击不敏感更可能是文本捷径；LLaGA 的 GT→label 直接映射可能解释其原始准确率高但 content-level 变化差；PRBCD 结果不能单独推出因果结构使用。
- 待核验：完整 released code/checkpoint 是否已在审稿后公开；各模型 graph token 是否严格保持节点顺序/边顺序的实现细节；在同一模型上补充 node permutation、isomorphic graph、text shuffle、held-out topology OOD 和语义保持的 counterfactual 结果。
