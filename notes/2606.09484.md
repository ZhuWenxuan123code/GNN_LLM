# Detecting Differences Is Not Understanding Structure: Large Language Models Fail at Graph Isomorphism

## 基本信息

- Paper ID：arXiv:2606.09484
- 作者：Kumar Thushalika；Sukumar Kishanthan；Asela Hevapathige
- 年份与发表状态：2026；arXiv v1，2026-06-08 提交，CC BY 4.0
- 论文页面：[arXiv abstract page](https://arxiv.org/abs/2606.09484)
- PDF：[arXiv PDF](https://arxiv.org/pdf/2606.09484)
- 阅读级别：全文精读
- 对应证据线：2, 6

## 一句话结论

这篇论文用同一图的随机节点重标记构造了直接的 permutation-invariance 检验：三个纯序列化 LLM 在普通 graph-isomorphism 检测上接近满分，却在保持拓扑不变的重标记对上只有 0-39.2% 的准确率，说明任务高分不能替代图不变量证据，但仍未触及 Graph-LLM 的因果结构利用。

## 研究问题与真实贡献

- 作者声称解决的问题：判断 LLM 是否真的理解 graph isomorphism，而不是只匹配 edge list、edge index 或 adjacency matrix 中的表面模式。
- 方法的真实新增部分：提出一个小而直接的两阶段 protocol。第一阶段测试非同构图识别，第二阶段将同一连通图随机重编号并生成同构副本，要求模型保持“isomorphic”判断不变；同时交叉比较三种 serialization 和 zero-shot/instructed prompting。
- 与已有方法相比的关键差异：重点不是提高 graph reasoning accuracy，而是把 ordinary isomorphism detection 与同拓扑 node relabeling invariance 分开测量。该论文不是 GNN-LLM hybrid，也没有 graph encoder、projector、graph token 或训练型结构瓶颈。

## “图结构”的具体含义

- 结构粒度：全局拓扑，具体是无节点属性的图对、节点数/边数/degree sequence、1-WL indistinguishable 的高阶结构，以及随机节点重编号后的同构关系。
- 图信息输入形式：同一图或图对被序列化为 edge list、edge index 或 adjacency matrix；实验没有节点文本、节点属性或自然语言 graph description。
- 信息路径：`Graph pair -> edge list/edge index/adjacency matrix serialization -> prompt -> LLM -> isomorphic/non-isomorphic output`。
- GNN 是否可能已经完成主要计算：没有 GNN。论文把全部判断交给 LLM；但随机重标记失败和格式差异说明 LLM 很可能主要依赖 serialization pattern、节点编号和 token/位置统计，而不是形成 permutation-invariant topology representation。

## 方法机制

实验使用 GPT-4o-mini、Gemini 2.5 Flash 和 Llama 3.3 70B Instruct，解码 temperature 为 0。每个模型分别接受 zero-shot prompt 和 instructed prompt；后者显式定义 graph isomorphism 并提示推理过程。三种输入格式是 edge list、edge index 和 adjacency matrix。

第一阶段包含 400 个非同构图对，每类 100 个，图规模为 8-15 个节点：类别 1 的边数相同但节点数不同；类别 2 的节点数相同但边数不同；类别 3 的节点数和边数都不同；类别 4 的节点数、边数和 degree sequence 都相同，但图的 cycle structure 和更高阶结构不同，且 1-WL 无法区分。第二阶段生成 400 个随机连通图，节点数分别为 5、10、15、20，每个图随机置换节点标签后生成同构副本，所有图对在拓扑上均为 isomorphic。

## 实验设计与结果

- 数据集与任务：随机生成的无属性图。任务一是判断非同构图对，任务二是判断随机节点重标记后的一对同构图是否 isomorphic。
- 数据划分：实验一按四种非同构难度类别各 100 对；实验二按节点数 5、10、15、20 各生成 100 个连通图及其随机置换副本。没有训练/测试学习 split，因为这是 zero-shot/in-context API 评测。
- Baseline：50% random-guess 作为二分类参照；模型 baseline 为 GPT-4o-mini、Gemini 2.5 Flash、Llama 3.3 70B Instruct；输入 baseline 为 edge list、edge index、adjacency matrix；prompt baseline 为 zero-shot 与 instructed。
- 主要指标与结果：
  - 非同构检测中，三种模型在三种格式上总体接近满分。OpenAI zero-shot 为 100.0/100.0/100.0%，instructed 为 99.8/98.8/91.5%；Gemini 所有格式和 prompt 均为 100.0%；Llama zero-shot 为 98.8/99.5/97.5%，instructed 为 99.0/98.2/100.0%。
  - 1-WL indistinguishable 的类别 4 仍被模型高准确率识别：OpenAI instructed 降至 88.0%，Gemini 为 100.0%，Llama 为 98.7%。这构成“可能使用高阶线索”的表面正面证据，但也使后续 permutation control 更必要。
  - 同构重标记任务中，OpenAI zero-shot 在 edge list、edge index、adjacency matrix 上分别为 0.0%、0.0%、0.5%，instructed 为 11.2%、16.0%、18.0%；Gemini 所有条件为 0-0.2%；Llama zero-shot 为 11.2%、6.0%、2.0%，instructed 为 31.5%、39.2%、4.5%。
  - 模型通常把随机重标记造成的 serialization 差异判断为 non-isomorphic；同一模型内部不同 serialization 的大幅变化也说明结果受输入格式和模式匹配影响。
- 关键消融：三种 serialization、zero-shot/instructed、随机节点重标记和四种非同构难度类别。没有 token embedding、节点编号分布、图自同构、结构属性匹配或模型层级 ablation。
- 是否足以支持作者结论：足以支持“在该三模型、三种序列化、随机图设置下，普通 graph-isomorphism 高准确率与 permutation invariance 严重脱钩”的有限结论；不足以支持“所有 LLM 都不能做结构推理”的普遍结论，也不能直接外推到 GraphGPT、LLaGA、IP-GLLM 或其他 GNN-LLM。

## 局限与潜在捷径

- 研究对象是纯文本序列化 LLM，不是 Graph-LLM hybrid；没有 GNN、graph tokenizer、continuous graph embedding、projector、readout 或 LLM responsibility split。
- 随机图没有显式控制 girth、diameter、symmetry、automorphism structure 等属性。某些图族可能更容易被序列模式识别，因而不能把失败唯一归因于 LLM 的“架构限制”。
- 图规模只覆盖 5-20 或 8-15 个节点，不能说明 larger graph、density shift 或 held-out topology family 的泛化。
- 实验只使用无属性节点和边；没有节点文本、语义标签、目标节点或任务相关局部结构，因此不能直接回答 text shortcut 与 topology shortcut 如何在 GNN-LLM 中竞争。
- 没有系统消融 tokenizer、token embedding、编号分布、prompt wording 或 API sampling；论文也明确把这些因素留作后续工作。
- 普通 isomorphism task 的近满分可能来自 size、edge count、degree sequence 或序列模式等可利用统计，而不是对 Category 4 的真实高阶拓扑推理。反过来，permutation 失败证明了行为不稳定，但不定位失败发生在 tokenization、attention、推理策略还是输出解析。

## 与当前研究的关系

- 支持或挑战的研究假设：强支持 H2 的“节点重编号和序列化顺序可能导致顺序捷径”，并对 H5 提供部分支持：普通 isomorphism accuracy 与 permutation robustness 可以明显分离。它补充 H1 的边界证据，但不改变“纯序列化 LLM 结果不能直接外推到 GNN-LLM”的原则。
- 可以复用的实验或方法：将“同一 graph + random node relabeling + prediction equality/flip rate”作为 GraphToken、IP-GLLM、HLM-G、EDT-Former 和 OOD-GraphLLM 的最小 invariance control；同时保留三种 serialization/encoding 和 instructed-vs-minimal prompt 对照。
- 尚未解决的关键问题：若 Graph-LLM 的 graph encoder 已经 permutation-invariant，connector、dynamic patch、LLM hidden state 和最终输出是否仍保持一致？通过 relabeling 的模型是否也能对 fixed-text 的关键拓扑做方向正确干预，并在 held-out topology family 上泛化？

## 可证伪的新想法

- 假设：对 Graph-LLM，ordinary graph-task accuracy 与同拓扑 node relabeling 的 prediction equality 是两个独立审计轴；即使模型在原始编号上高分，若 relabeling flip rate 高，则不能称为稳定的图结构表征。该假设在纯 LLM 边界案例中获得部分支持，但对 GNN-LLM 仍待验证。
- 最小实验：对同一批固定节点文本/特征和同一任务，生成 10 次 node relabeling，并同时生成 equivalent-SMILES 或 edge-order variants；在 GraphToken、IP-GLLM、HLM-G、EDT-Former 上记录逐样本 prediction equality、输出分布 KL、hidden-state distance 和最终答案 flip rate，再对同一批图只改变关键边/无关边，测 direction accuracy。
- 对照组：原始 Graph-LLM、GNN-only、LLM-only、encoder/readout-only、text-only、shuffled graph embedding、random-label/text shuffle，以及 edge list、edge index、adjacency-like 或 canonical/random SMILES serialization。
- 支持条件：同拓扑重标记和等价序列化下 prediction equality 高；关键 topology intervention 按预注册方向改变输出；无关干预保持稳定；完整模型的 direction accuracy 超过 readout-only/text-only，并在 held-out topology family 保持。
- 失败或否定条件：普通任务准确率高但 relabeling flip rate 接近随机；关键干预无响应或方向错误；readout-only/GNN-only 复现完整模型；或格式/节点编号变化足以改变 connector/LLM hidden state 和最终输出。

## 可信度与待核验项

- 直接由全文支持的事实：论文标题、作者、arXiv v1 日期、三种 LLM、两种 prompt、三种 serialization、400 对非同构图、400 个随机连通图、节点规模、四类非同构任务、表 1-3 的主要数值、重标记失败范围和作者列出的限制，均来自 arXiv 官方 HTML 与本地 PDF。
- 我的推断：模型依赖 serialization pattern、节点编号和 token/位置统计；普通 isomorphism 高分与 permutation invariance 失败说明二者是可分离行为；该结果不能证明任何 Graph-LLM 的 LLM causal topology use。这些是基于实验行为与研究纲领的解释，不是作者已经完成的因果定位。
- 待核验：需要在控制 girth、diameter、symmetry、automorphism、tokenization 和模型随机性的条件下复现；需要把 protocol 迁移到带节点文本/特征的 GNN-LLM，并增加 fixed-text key/irrelevant topology intervention、GNN-only/LLM-only/readout-only 和 topology-family OOD。
