# When Structure Doesn't Help: LLMs Do Not Read Text-Attributed Graphs as Effectively as We Expected

## 基本信息

- Paper ID：arXiv:2511.16767
- 作者：Haotian Xu、Yuning You、Tengfei Ma
- 年份与发表状态：2026，arXiv v2（2026-04-30）；论文页标注为 LoG 2025 extended abstract
- 论文页面：https://arxiv.org/abs/2511.16767
- PDF：https://arxiv.org/pdf/2511.16767；本地归档：`papers/2026_Xu_When_Structure_Doesnt_Help.pdf`
- 阅读级别：全文精读
- 对应证据线：1、5、6；同时为“结构必要性是否可识别”提供反面证据

## 一句话结论

在语义丰富的 text-attributed graph 和分子任务上，语义-only、中心节点或 MLP 基线常能达到与结构增强方法相当甚至更好的结果，但由于邻居采样、文本—标签相关性和随机划分仍未被因果控制，这构成对“结构普遍有益”的反证而不是对 LLM 完全不使用拓扑的证明。

## 研究问题与真实贡献

- 作者声称解决的问题：重新检验 text-attributed graph（TAG）中把 Laplacian positional encoding、邻居结构模板或 GNN adapter 注入 LLM 是否真的带来必要且稳定的收益，并考察模型规模、语义信息量、数据集规模、分子结构和更强 reasoning model 是否改变结论。
- 方法的真实新增部分：在统一的 Vicuna/LLM 对齐设置中比较 LLaGA 的 Neighborhood Detail（ND）、Hop Neighbor（HN-1）和 Center Only（CO）模板；在 GraphToken 中用 MLP 替换 GCN/GAT/GIN；在 BACE、BBBP、HIV 和 Davis DTI 上比较 MLP/序列 encoder 与图 encoder；再加入模型规模、稀疏/完整文本、Products/ArXiv 和 GDC 节点序列变换分析。
- 与已有方法相比的关键差异：论文把“结构增益”转化为结构-aware 与结构弱化/无 message-passing 的匹配比较，并将结果解释为语义充分性、结构噪声和 adapter over-smoothing 的问题；它没有提出新的 graph tokenizer，也没有 graph-level counterfactual 或 hidden-state mediation 协议。

## “图结构”的具体含义

- 结构粒度：TAG 中的中心节点及其 k-hop 邻居、Laplacian positional encoding、模板构造的局部计算图；分子图中的 atom-bond connectivity；Davis 中 molecule/protein 的结构 encoder。
- 图信息输入形式：ND 使用预定义的 node-centered k-hop B-tree 与 Laplacian embedding；HN-1 从 k-hop 邻居随机选取节点描述并形成较弱结构序列；CO 只保留中心节点描述。GraphToken 分支把节点/结构表示经 GNN 或 MLP adapter 变成 LLM 输入；分子分支把 atom-level 表示送入 MLP/GNN adapter。
- 信息路径：`TAG graph → ND/HN-1/CO template 或 GraphToken GNN/MLP adapter → text/graph embeddings → Vicuna-7B/LLM → node classification/link prediction`；分子路径为 `molecule graph → GraphMVP/GCN/GAT/GIN 或 TinyBERT/MolFormer/ESMv2 → Llama3-8B → molecular property/DTI output`。
- GNN 是否可能已经完成主要计算：是，且责任未闭合。GraphToken 的 GNN adapter、分子 GNN encoder、GraphMVP/GearNet 都可能预先完成局部聚合和结构压缩；MLP 对照削弱了 message passing，但 HN-1 的邻居选择和输入序列仍由图决定，不能把它们简单当作完全 structure-free。

## 方法机制

主实验以 Vicuna-7b-v1.5 为 LLM backbone，使用预训练语言 encoder 产生节点或 atom 的语义表示，再通过模板或 adapter 注入 LLM。ND 使用 LLaGA 风格的中心节点和邻居结构、Laplacian positional encoding 与固定的局部计算路径；HN-1 随机抽取 k-hop 邻居描述，CO 只输入中心节点。GraphToken 分支保持其他训练配置不变，用 MLP 替换 GCN、GAT、GIN，观察去除 message passing 后性能是否保持。论文还比较 Llama2-7B/13B、OpenReasoning-Nemotron-7B，并在 Davis DTI 中使用 Llama3-8B 对比 GraphMVP+GearNet 与 MolFormer+ESMv2。主设置使用 AdamW、DeepSpeed、3 个随机种子；附录给出 8 张 A6000、每卡 batch size 4、template learning rate `2e-3`、GNN learning rate `1e-4` 和各数据集训练时间。

## 结构证据审计

| 证据问题 | 是否提供 | 论文证据 | 我的判断 |
|---|---|---|---|
| 结构被输入 | 是 | ND、HN-1、GraphToken GNN adapter 和分子 GNN encoder 都把邻居/图表示送入 LLM | 直接证明结构或由图选择的上下文进入系统，但不证明 LLM 内部做了主要拓扑计算 |
| 结构可由中间表示解码 | 否 | 论文比较下游准确率、adapter 和 encoder，没有 node/edge/graph IR probe | 不支持结构可解码结论 |
| 节点置换或同构一致性 | 否 | 没有 node relabeling、edge order、isomorphic pair 或输出 equality | 不能判断结构输入是否遵守图不变量 |
| 结构反事实干预 | 否 | ND、HN-1、CO、MLP/GNN 和 GDC 是条件或模块替换，没有固定文本下的关键/无关 topology matched pair | 结构敏感性与因果拓扑干预仍未测量 |
| 结构被最终预测因果利用 | 否 | MLP/CO/HN-1 可达到或超过 GNN/ND，但没有 mediation、direction accuracy 或 responsibility split | 只能说明结构增益在这些任务上不稳定，不能证明 LLM 不使用拓扑 |
| 跨规模、密度或拓扑泛化 | 部分 | 覆盖 6 个 TAG、Products/ArXiv、BACE/BBBP/HIV、Davis DTI、不同 LLM size 和 GDC | 是跨数据集/模型/部分规模压力测试，但主要是随机 8:2 split，不是 held-out topology-family OOD |
| 排除文本或预训练捷径 | 部分 | CO、稀疏/完整 node description、MLP、不同 encoder、模型规模、GDC 和多数据集比较 | 直接暴露语义捷径和 adapter over-smoothing，但没有 text shuffle、random-label、数据 cutoff 控制或 fixed-text topology intervention |

## 实验设计与结果

- 数据集与任务：Cora、Citeseer、Pubmed、School、Roman Empire、Amazon Ratings 的 node classification/link prediction；BACE、BBBP、HIV 的 molecular property prediction；Davis Drug–Target Interaction 的 molecule-protein prediction。TAG 同时覆盖 homophilic citation graph、heterophilic webpage/e-commerce/dependency graph。
- 数据划分：附录说明各数据集采用 8:2 train-test split；没有按 graph generator、topology family、diameter 或 node permutation 划分。Davis 的结构 encoder 与 sequence encoder 还混合了不同预训练体系。
- Baseline：LLaGA ND、HN-1、CO；GraphToken 的 MLP、GCN、GAT、GIN adapter；GraphMVP+GearNet 与 MolFormer+ESMv2；Llama2-7B/13B、Vicuna-7B、OpenReasoning-Nemotron-7B、Llama3-8B 等模型配置。
- 主要指标与结果：TAG Table 2 的 node-classification across-dataset accuracy 为 ND/HN-1/CO=`69.48/74.49/75.29%`，link prediction 为 ND/HN-1=`81.83/83.91%`；GraphToken Table 3 的 node-classification 平均为 MLP/GCN/GAT/GIN=`76.26/67.50/67.07/68.24%`，link prediction 为 `75.19/75.51/74.70/72.57%`。分子 Table 4 中 BACE 的 MLP 为 `58.99%`、GCN `58.77%`，HIV 为 `96.85/96.81%`；只有 BBBP 中 GIN `60.29%` 高于 MLP `54.57%`。Products 与 ArXiv 的 ND/HN-1 node classification 分别为 `83.45/83.87%`、`75.65/75.41%`，文中报告 Welch t-test 的 `p_products=0.20`、`p_arxiv=0.49`。
- 关键消融：adapter 深度增加时 GCN/GAT/GIN 性能波动或下降，MLP 更稳定；Llama2 从 7B 增至 13B 没有稳定提升结构-aware ND 相对 HN-1 的能力；在 sparse/full node descriptions 下 HN-1 仍经常匹配或超过 ND；OpenReasoning-Nemotron-7B 也没有因为 Laplacian embedding 获得稳定收益；GDC 通过扩展并稀疏化邻域、压缩中心节点序列，在部分设置中改善性能。
- 是否足以支持作者结论：足以支持“在这些语义丰富、主要随机划分的任务上，显式结构编码不是稳定的必要条件，GNN adapter 可能过平滑，节点序列选择有影响”；不足以支持“LLM 只读语义、不读取拓扑”或“结构对 Graph-LLM 普遍无用”，因为 HN-1 仍利用图驱动的邻居选择，且没有结构必需任务、固定文本 topology pair 和组件责任闭环。

## 局限与潜在捷径

### 作者明确承认的 limitation

- 论文指出现有 graph benchmark 可能没有反映真实的 relational complexity，许多标准任务可能不需要或甚至不奖励 structural reasoning；因此结论需要放在 benchmark/task 条件下理解。
- GDC 研究被定位为 preliminary study；作者只说长程结构压缩和语义引导的结合值得后续研究，没有把它包装为完整方法。
- 论文在 appendix 中固定使用 Vicuna-7B、8 张 A6000 和 3 个随机种子作为主实验资源边界，不能据此外推到任意更大 LLM。

### 实验直接暴露的不足

- HN-1 和 CO 在多个 TAG 数据集上超过 ND，说明 Laplacian positional encoding 与预定义结构模板的增益不稳定；School 上 ND 为 `66.43%`、HN-1 为 `82.02%`、CO 为 `91.13%`，结构上下文甚至可能显著伤害 node classification。
- GraphToken 的 MLP 在平均 node classification 上高于 GCN/GAT/GIN，且更深的 GNN adapter 下降明显，直接暴露 over-smoothing、结构噪声或优化不匹配的可能性。
- 分子任务中 MLP 与结构 GNN 大多接近，Davis 中 sequence encoders 的 MSE 为 `1.1103±0.0114`，结构 encoders 为 `1.1349±0.0100`，说明“天然结构任务一定需要图 encoder”并不由该实验成立。
- GDC 的局部改善说明结构变换仍可能有用；这与“结构完全无用”冲突，较符合“合适的节点序列/结构压缩比显式结构模块更重要”的解释。

### 研究者推断、尚待验证的不足

- HN-1 不是严格的 structure-free baseline：它用 graph connectivity 选择 k-hop neighbors；MLP 也可能保留输入节点序列、相似图或邻居采样带来的隐性结构信息。因此 MLP/HN-1 的强结果不能直接归因于纯语义。
- Cora、Citeseer、Pubmed、School 等节点标签与文本主题、同配性和数据集构造强相关；中心节点文本已经可能携带足够标签信息。需要在标签与节点文本解耦、或结构决定标签的 matched task 上复核。
- 8:2 random split 允许相似文本、相似局部结构和相同生成机制同时出现在 train/test，未测 topology-family OOD；模型可能在标准 split 上只依赖语义或局部模板。
- GNN 与 MLP、GraphMVP 与 TinyBERT/MolFormer 的容量、预训练语料、归一化和优化路径并非完全等价；性能接近不能自动说明结构被忽略。
- DTI 的 sequence-versus-structure encoder 比较同时改变了模态、预训练和输入长度，单个 Davis MSE 不足以定位 LLM 对 topology 的责任。

## 与当前研究的关系

- 支持或挑战的研究假设：强力支持 H1 的“任务增益不等于 LLM causal topology use”；对 H3 的“显式结构瓶颈普遍优于 projector/语义-only”施加反驳证据；支持 H5 的能力分轴要求；为 H10 增加“semantic sufficiency 与 structure necessity 必须分层”的条件化视角，并为 H11 的 GNN/LLM 责任不确定性增加 MLP/GNN 对照证据。
- 可以复用的实验或方法：ND/HN-1/CO 三层模板、MLP-versus-GNN matched adapter、sparse-versus-full semantic content、Products/ArXiv size pressure、预训练 graph encoder versus language encoder、GDC 的中心化序列选择；这些应迁移到 fixed-text topology-pair protocol。
- 尚未解决的关键问题：结构增强在什么任务条件下才是可识别的必要信息？当保持节点文本、prompt 和输出格式不变而只改变 key/irrelevant edge 时，MLP、readout-only 和完整 Graph-LLM 是否能分别表现出无响应、伪响应和方向正确响应？

## 可证伪的新想法

- 假设：Graph-LLM 的结构收益是 task-conditional 的；只有在 node text/label 语义不足以完成任务、且 topology intervention 在固定文本下方向正确时，离散结构接口才有资格被称为有效结构瓶颈。若 semantic-only、neighbor-selection 或 readout-only 在 structure-essential matched tasks 上复现完整模型，则 I1 的方法增益解释失败。
- Idea 推导链：今日论文显示 semantic-only/MLP/中心节点常可复现结构-aware系统 → 可能机制是文本—标签相关性、HN-1 的图驱动邻居选择、GNN over-smoothing 和随机 split 捷径 → 在 I1 中先增加 semantic-sufficiency gate，再在结构必需任务上加入 reversible/discrete addressable tokens、等价变换 consistency 和 fixed-text key/irrelevant topology intervention → 观察 serialized/BPE equality、hidden/output stability、direction accuracy、irrelevant stability 与 topology-family OOD 是否共同改善。
- 结合的历史论文：GraphTokenizer（arXiv:2603.11099）的 reversible/deterministic discrete interface；GTEval（arXiv:2605.03514）的 instruction/content robustness 与 text reliance；Lost in Serialization（arXiv:2511.10234）的 relabeling/order/syntax/OOD 分解；CausalGraph2LLM（doi:10.18653/v1/2025.findings-naacl.110）的 `do(X=x)` 方向诊断。
- 最接近工作：Huang et al.（arXiv:2309.16595/TMLR）的 contextual-paragraph 与 label-relevant phrase 分析；GraphToken（arXiv:2402.05862）的结构输入正向收益；GTEval（arXiv:2605.03514）的 GTokenLLM 统一审计；GraphTokenizer（arXiv:2603.11099）的 reversible/BPE tokenizer。
- 与相邻工作的最小实质差异：不是再增加一个 semantic ablation、MLP baseline、relabeling test 或 structural token，而是先用 matched semantic-sufficient/structure-essential task split 判断结构增益是否可识别，再在同一 Graph-LLM 上联合执行 `10 relabelings × edge-order/start-direction`、decode isomorphism、fixed-text key/irrelevant topology intervention、parser/GNN/LLM/readout responsibility split 和 topology-family OOD。
- Novelty 状态：已初步区分；semantic shortcut 与结构无必要性已有直接相邻证据，I1 的 Novelty 仍记 `1/2`，当前可辩护差异是联合协议与结构必要性 gate，不使用“首次”“首个”等强断言。
- 最小实验：构造两组同样长度、同样 node text/prompt 的 graph pairs：A 组标签可由中心文本预测，B 组标签由 shortest-path/connectivity/cycle 等 topology 决定；对两组执行 raw text、HN-1/CO、MLP adapter、GNN/GraphTokenizer、readout-only 和 LLM-only。B 组再执行 node relabeling、edge order、fixed-text key/irrelevant edge intervention，并记录 prediction equality、output KL、direction accuracy 和 topology-family holdout。
- 对照组：semantic-only center text、HN-1 neighbor selection、random-label/text shuffle、GraphToken MLP/GNN、GraphTokenizer reversible/BPE、Graph-KV mask-only、GRAIN parser/oracle、solver-disabled、GNN-only、readout-only、LLM-only、natural/opaque labels。
- 支持条件：A 组允许语义-only 与结构模型接近；B 组中完整 I1 相对 semantic-only、MLP、readout-only 有稳定增量，等价变换下 output equality 高，key intervention direction accuracy 高、irrelevant stability 高，并在 topology-family OOD 保持优势。
- 失败或否定条件：A/B 两组都由中心文本或 readout-only 复现；HN-1/MLP 的图驱动序列已解释全部提升；relabeling 或 edge order 造成 token/output flip；关键拓扑无方向响应；或只提升 standard split/压缩率而 topology-OOD 失败。
- 资源和实现风险：第一阶段只需 CPU 合成小图、节点文本和 parser/readout baseline；GraphTokenizer runtime 仍需隔离安装 `torch、dgl、networkx、rdkit、transformers`，完整 LLaGA/GraphToken 复现需 GPU。不能把论文已有的 8×A6000 训练结果当成本地复现。

## 可信度与待核验项

- 直接由全文支持的事实：ND/HN-1/CO 模板比较；GraphToken 的 MLP/GNN adapter 比较；BACE/BBBP/HIV、Davis、Products/ArXiv、Llama2 scale、sparse/full semantics 和 GDC 分析；主要准确率、MSE、8:2 split、3 seeds 与 8×A6000 配置。
- 我的推断：semantic-only 和 HN-1 的强结果可能混入文本—标签相关性、graph-driven neighbor selection、序列顺序和 split shortcut；MLP/GNN 差异不能单独定位 LLM responsibility；该论文提供结构必要性反证而非 graph-level causal proof。
- 待核验：在节点文本与标签解耦的 structure-essential tasks 上复现 HN-1/MLP/GNN 对照；执行 node relabeling、edge-order、fixed-text key/irrelevant topology intervention；比较 GNN-only/readout-only/LLM-only；对 DTI 与分子任务加入 equivalent representation 和 scaffold/topology-family OOD；复核官方代码的 split 与数据预处理。
